# Trista built-in styles

This folder contains presets that can be used by the Trista editor.

Each preset is intentionally simple and client-side. The editor can load these JSON files later without a backend.

## Presets

- `minimal.json` — clean neutral layout
- `soft.json` — rounded, friendly UI
- `contrast.json` — strong contrast and clear controls

These are **project styles**, not Trista application settings.
